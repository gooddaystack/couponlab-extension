# Privacy

The live policy is [https://www.couponlab.com/privacy](https://www.couponlab.com/privacy).

CouponLab 1.4 reads the current tab URL only after you click the icon. It uses that host to open the matching shop in the popup. It does not read the page body and it does not type a code into checkout.

A packed catalog is bundled. A live refresh fetches JSON from `https://www.couponlab.com`. That response is data, not a script. Nothing is saved to an account.
